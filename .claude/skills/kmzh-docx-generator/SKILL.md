# Генерация ҚМЖ: Word-шаблон + Gemini + Next.js

Как это работает: учитель заполняет форму → сервер делает ОДИН запрос к Gemini → Gemini возвращает JSON строго по схеме → docxtemplater подставляет JSON в готовый шаблон → учитель скачивает .docx. Оформление (таблицы, шрифт 12 pt, жирные заголовки, ширина колонок) берётся из шаблона и не меняется.

Стек: Next.js (App Router, TypeScript), Vercel, `docxtemplater` + `pizzip`, `@google/genai`.

## Что лежит в скилле

| Файл | Зачем |
|---|---|
| `templates/kmzh.docx` | Шаблон ҚМЖ пользователя, уже размеченный тегами. Проверен: заполняется без ошибок, вёрстка совпадает с оригиналом |
| `examples/sample.json` | Полностью заполненный пример данных (физика, 8 класс). Это и тестовые данные, и образец для промпта Gemini |
| `scripts/test-fill.mjs` | Заполняет шаблон данными из JSON и проверяет, что не осталось тегов |
| `scripts/build_template.py` | Как шаблон был размечен. Нужен, только если пользователь пришлёт новый вариант шаблона с той же структурой |

## Общие правила

- Код простой и читаемый. Не дробить на много мелких функций, без хитрых конструкций.
- Не трогать вспомогательные функции, которые пользователь попросил оставить как есть.
- Ключ Gemini только на сервере: `GEMINI_API_KEY` (никогда не `NEXT_PUBLIC_`). Модель — из `GEMINI_MODEL` (ID модели взять в Google AI Studio), не хардкодить.
- Не редактировать `kmzh.docx` руками в Word: теги могут развалиться на куски. Если нужно поменять разметку — правь `build_template.py` и пересобери.

## Структура шаблона

Шапка (таблица 1, вторая колонка):

| Тег | Что | Кто заполняет |
|---|---|---|
| `{teacher_name}` | Педагогтің аты-жөні | учитель |
| `{date}` | Күні | учитель |
| `{grade}` | Сынып (после него в ячейке статичный текст «Қатысқандар саны: / Қатыспағандар саны:») | учитель |
| `{section}` | Бөлім | учитель |
| `{topic}` | Сабақтың тақырыбы | учитель |
| `{learning_objective}` | Оқу бағдарламасына сәйкес оқу мақсаты (с кодом, напр. «8.3.2.17 – ...») | учитель |
| `{lesson_goal}` | Сабақтың мақсаты | Gemini |

Основная таблица: 8 строк-этапов. Первая колонка (название этапа и время) статична — в шаблоне. Итого 45 минут.

| Префикс | Этап (колонка 1 шаблона) | Время |
|---|---|---|
| `org` | Ұйымдастыру кезеңі | 3 мин |
| `start` | Сабақтың басы — Функционалдық сауаттылық | 7 мин |
| `new` | Сабақтың ортасы — Жаңа білім | 7 мин |
| `task1` | 1-тапсырма — ЖИ сауаттылығы | 8 мин |
| `task2` | 2-тапсырма — Құндылыққа негізделген | 7 мин |
| `task3` | 3-тапсырма — Жеке жұмыс | 8 мин |
| `sen` | ЕБҚ оқушысына арналған (ерекше білім беру қажеттілігі) | — |
| `end` | Сабақтың соңы — Бағалау (рефлексия, үй тапсырмасы) | 5 мин |

Для каждого префикса `X`:
- `X_teacher` — массив блоков `{ title, text }`. Каждый блок — отдельный абзац: `title` жирным (метод «...» тәсілі, «Күтілетін жауап:», «Саралаудың ... тәсілі:», «Үй тапсырмасы:»), потом обычный `text`. `title` может быть пустым. `\n` внутри `text` = перенос строки.
- `X_student` — Оқушының іс-әрекеті, строка.
- `X_assessment` — Бағалау, строка (можно с `\n`).
- `X_resources` — Ресурстар, строка.

Дополнительно:
- `task1_descriptors` — массив строк, без баллов (выводится строкой «Дескрипторлар: a; b; c.»).
- `task2_points` = 4, `task3_points` = 6, `sen_points` = 10 и `task2_descriptors` / `task3_descriptors` / `sen_descriptors` — массивы `{ text, points }`. Сумма `points` ОБЯЗАТЕЛЬНО равна `X_points`. Выводятся как «4 балл:» и строки «• текст — 1;».

Перед рендером данные готовятся (так же, как в `scripts/test-fill.mjs`):
- в каждый блок `X_teacher` добавить `sp: title ? ' ' : ''` (пробел между жирным заголовком и текстом);
- `task1_descriptors` склеить в строку через `'; '` с точкой в конце.

## Какими должны быть задания (по образцам пользователя)

Это главное для качества — переносится в промпт Gemini.

**Общее**
- Язык — казахский литературный, обращение к классу во 2-м лице мн. ч. в заданиях («табыңдар», «түсіндіріңдер»).
- Каждый этап учителя начинается с названия метода жирным: «"...» тәсілі.» Форма работы в начале: «Топтық жұмыс.», «Жұптық жұмыс.», «Жеке жұмыс».
- Каждое задание содержит: условие → пронумерованные вопросы 1) 2) 3) 4) → блок «Күтілетін жауап:» (или «Жауаптар:») с полным решением → блок «Саралаудың ... тәсілі:» (как поддержать слабых / нагрузить сильных).
- Все числа реальные, с единицами измерения; каждое вычисление в «Күтілетін жауап» расписано (500 − 200 = 300 Дж) и проверено.
- Формулы — Unicode-символами: ΔU, ρ, A′, V₂, м³, м/с², ×10⁻³. Без LaTeX и markdown.
- Номера параграфов, страниц и рисунков учебника писать ТОЛЬКО если учитель указал их в поле «Оқулық» (`textbook_ref`). Иначе — общие ресурсы: «оқулық», «тақта», «үлестірме парақ».
- Код оқу мақсаты не придумывать — он приходит от учителя.

**Сабақтың басы (функционалдық сауаттылық)** — 2 жизненные ситуации-вопроса («неге?») + «Болжам жаса»: проблемный вопрос, ведущий к теме. В заголовках блоков указать минуты. Балл қойылмайды.

**Сабақтың ортасы (жаңа білім)** — объяснение по пунктам: определение, формула, расшифровка величин и единиц, знаки/частные случаи, главный вывод. 3–4 блока, первый с методом.

**1-тапсырма, ЖИ сауаттылығы (топтық)** — учитель даёт «шартты ЖИ жауабы»: правдоподобный ответ ИИ по теме с ОДНОЙ намеренной ошибкой (неверная формула, знак, единица или понятие). Фраза «Интернет қажет емес.» 3–4 вопроса: найти ошибку, различить понятия, показать верный расчёт, объяснить. Ученики распределяют роли (мәтінді талдаушы, есептеуші, баяндамашы). 3–4 дескриптора без баллов. Бағалау: «Бас бармақ» әдісі, бір-бірін бағалау.

**2-тапсырма, құндылыққа негізделген (жұптық)** — ситуация из жизни или национальный контекст (ұсталар, зергер, көкпар, киіз үй, ауыл шаруашылығы и т.п.), связанный с темой. 3–4 вопроса + «Күтілетін жауап». Явно назвать ценность: әділдік, жауапкершілік, адалдық, еңбекқорлық (или «апта құндылығы», если учитель указал). Роли в паре меняются. 4 балл: 4 дескриптора по 1.

**3-тапсырма, жеке жұмыс** — 2 расчётные задачи с конкретными числами + «Жауаптар:» с решением + «Қосымша саралау:» одна задача посложнее с ответом, с пометкой «Негізгі 10 балға қосылмайды.» 6 балл: по 3 дескриптора на задачу (формуланы қолданады — 1; нәтижені табады — 1; мағынасын түсіндіреді — 1). Для нематематических предметов — 2 практических задания такого же объёма.

**ЕБҚ оқушысы** — «Мұғалімнің көмегімен орындалатын жеке тапсырма.»: 1) выбрать верное слово из двух; 2) дополнить предложение (с «Тірек сөз»); 3) простой расчёт по готовой формуле. Как помогает учитель. «Күтілетін жауаптар:». 10 балл: 5 дескрипторов по 2. Бағалау: «Негізгі тапсырмалардың балдары қосылмайды.»

**Сабақтың соңы** — «Шығу билеті» тәсілі: 3 вопроса (объясни закон одним предложением; мини-расчёт; что ещё трудно) + «Күтілетін жауап:» + «Рефлексия:» + «Үй тапсырмасы:». В бағалау: «Жұптық жұмыс — 4 балл, жеке жұмыс — 6 балл. Барлығы — 10 балл.»

## Шаг 1. Перенести файлы в проект

- `templates/kmzh.docx` → `templates/kmzh.docx` в корне проекта.
- `examples/sample.json` → `lib/kmzh/sample.json`.
- `scripts/test-fill.mjs` → `scripts/test-fill.mjs`.
- `npm i docxtemplater pizzip @google/genai`.
- Прогнать `node scripts/test-fill.mjs templates/kmzh.docx lib/kmzh/sample.json tmp/kmzh-test.docx` → должно быть «OK, no leftover tags».

## Шаг 2. Типы и схема — `lib/kmzh/schema.ts`

- TypeScript-тип `KmzhAiData` со всеми полями, которые пишет Gemini (`lesson_goal` и всё с префиксами этапов).
- `responseSchema` для Gemini через `Type` из `@google/genai`: `OBJECT` со всеми полями в `required`; `X_teacher` — `ARRAY` из `OBJECT {title: STRING, text: STRING}`; дескрипторы с баллами — `ARRAY` из `OBJECT {text: STRING, points: INTEGER}`; `X_points` — `INTEGER`.
- Поля учителя (`teacher_name`, `date`, `grade`, `section`, `topic`, `learning_objective`, `textbook_ref`) в схему Gemini НЕ входят — они идут в промпт как контекст и напрямую в шаблон.

## Шаг 3. Запрос к Gemini — `lib/kmzh/gemini.ts`

Одна функция `generateKmzh(input)`, один запрос на один ҚМЖ (на бесплатном тарифе мало запросов в минуту и в сутки).

```ts
import { GoogleGenAI } from '@google/genai';

const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });

const response = await ai.models.generateContent({
  model: process.env.GEMINI_MODEL!,
  contents: prompt,
  config: {
    responseMimeType: 'application/json',
    responseSchema: kmzhSchema,
    temperature: 0.4, // ниже — меньше ошибок в расчётах
    maxOutputTokens: 8192,
  },
});
const data = JSON.parse(response.text ?? '{}');
```

Промпт собрать из частей:
1. Роль: тәжірибелі мұғалім, ҚР жаңартылған оқу бағдарламасы бойынша ҚМЖ құрастырады. Сабақ 45 минут.
2. Данные учителя: пән, сынып, бөлім, тақырып, оқу мақсаты (код), оқулық (если есть), апта құндылығы/дәйексөзі (если есть).
3. Правила из раздела «Какими должны быть задания» — перенести целиком (можно перевести на казахский).
4. Образец: содержимое `sample.json` (без полей учителя) с пометкой «это образец стиля и объёма для другой темы — не копировать содержание».
5. «Жауапты тек JSON схемасы бойынша бер. Барлық есептеулерді тексер.»

Проверка ответа (в той же функции, просто и подряд):
- все поля из схемы на месте, массивы не пустые;
- `X_points` = 4 / 6 / 10 и сумма `points` в дескрипторах совпадает;
- если что-то не так — ОДИН повторный запрос; если снова не так — вернуть ошибку «ҚМЖ құрастыру сәтсіз аяқталды, қайталап көріңіз».
- ошибка 429: подождать 5 секунд и повторить, максимум 2 раза; потом сообщение «Сервис уақытша бос емес, бір минуттан кейін қайталаңыз».

## Шаг 4. API-роут — `app/api/kmzh/route.ts`

```ts
import fs from 'fs';
import path from 'path';
import PizZip from 'pizzip';
import Docxtemplater from 'docxtemplater';
import { generateKmzh } from '@/lib/kmzh/gemini';

export const runtime = 'nodejs'; // нужен fs, не edge
export const maxDuration = 60;    // генерация занимает 10–30 секунд

export async function POST(req: Request) {
  const input = await req.json();
  if (!input.topic || !input.grade || !input.learning_objective) {
    return Response.json({ error: 'Тақырып, сынып және оқу мақсаты міндетті' }, { status: 400 });
  }

  const ai = await generateKmzh(input); // при ошибке — вернуть 500/429 с текстом
  const data: any = { ...input, ...ai };

  // подготовка, как в scripts/test-fill.mjs
  for (const key of ['org', 'start', 'new', 'task1', 'task2', 'task3', 'sen', 'end']) {
    data[key + '_teacher'] = data[key + '_teacher'].map((b: any) => ({
      title: b.title || '', sp: b.title ? ' ' : '', text: b.text || '',
    }));
  }
  data.task1_descriptors = data.task1_descriptors.join('; ') + '.';

  const templatePath = path.join(process.cwd(), 'templates', 'kmzh.docx');
  const zip = new PizZip(fs.readFileSync(templatePath));
  const doc = new Docxtemplater(zip, { paragraphLoop: true, linebreaks: true });
  doc.render(data);
  const buffer = doc.getZip().generate({ type: 'nodebuffer', compression: 'DEFLATE' });

  const fileName = encodeURIComponent(`ҚМЖ_${input.topic}.docx`);
  return new Response(buffer, {
    headers: {
      'Content-Type': 'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
      'Content-Disposition': `attachment; filename*=UTF-8''${fileName}`,
    },
  });
}
```

В `next.config` добавить, чтобы шаблон попал в серверную функцию на Vercel:
`outputFileTracingIncludes: { '/api/kmzh': ['./templates/**'] }`.

## Шаг 5. Форма на сайте

Поля: педагогтің аты-жөні, күні, пән, сынып, бөлім, сабақтың тақырыбы, оқу мақсаты (код + текст), оқулық (параграф/беттер, необязательно), апта құндылығы (необязательно). Обязательные: сынып, тақырып, оқу мақсаты.

Кнопка «ҚМЖ құрастыру» → `fetch('/api/kmzh', { method: 'POST', body: JSON.stringify(form) })` → если `res.ok` — `res.blob()` и скачивание через `URL.createObjectURL`; иначе показать `error` из JSON. Пока идёт запрос — кнопка заблокирована, текст «Құрастырылуда… (30 секундқа дейін)».

## Шаг 6. Проверка перед сдачей

1. `node scripts/test-fill.mjs ...` — «OK, no leftover tags».
2. `npm run dev`, сгенерировать 2 ҚМЖ на разные темы (одна — не физика). Открыть .docx (или `soffice --headless --convert-to pdf`) и проверить:
   - все ячейки заполнены, тегов `{...}` нет, таблица не поехала;
   - жирные заголовки методов на месте, казахские буквы (ә, ғ, қ, ң, ө, ұ, ү, һ, і) и символы (Δ, ρ, ³) отображаются;
   - расчёты в «Күтілетін жауап» верные (пересчитать вручную), баллы 4 + 6 = 10, ЕБҚ = 10;
   - нет выдуманных страниц учебника, если `textbook_ref` пустой.
3. `npm run build` без ошибок.
4. Коротко сообщить пользователю: какие файлы созданы, какие env-переменные добавить в Vercel (`GEMINI_API_KEY`, `GEMINI_MODEL`), где править правила заданий (промпт в `lib/kmzh/gemini.ts`).

## Если пользователь меняет шаблон

- Поменялись только тексты/оформление при той же структуре (7 строк шапки, 9 строк основной таблицы) — `python3 scripts/build_template.py новый.docx templates/kmzh.docx` (нужен `pip install lxml`), затем шаг 6.
- Поменялась структура (другие строки/этапы) — поправить номера строк и префиксы в `build_template.py`, схему, `sample.json` и промпт, затем шаг 6.
