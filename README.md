Sabaq AI — сайт для учителей Казахстана. Учитель вводит тему урока, выбирает предмет и класс — и получает готовую презентацию PowerPoint и игру для класса. Всё можно поправить в конструкторе, а игру провести прямо на уроке: ученики отвечают со своих телефонов по QR-коду.

## ✨ Возможности

### 📊 Презентации
- **Генерация по теме** — AI (Google Gemini) пишет содержание урока: цели, примеры, вопросы. Можно начать и с пустого проекта с подсказками.
- **Виды презентаций** — урок, открытый урок, отчёт, доклад, классный час, родительское собрание, аттестация.
- **Стили оформления** — несколько шаблонов с разными цветами и шрифтами.
- **Конструктор по слайдам** — миниатюры, правка каждого поля, кнопка «AI» у отдельного слайда, отмена изменений, автосохранение.
- **Картинки** — подбираются сами из Wikimedia Commons, с подписью автора.
- **Скачивание в PPTX** — файл открывается в PowerPoint, в том числе в старых версиях.

### 🎲 Игры для класса
- **Тест**, **Викторина**, **Правда или ложь**, **«Өз ойын»** (как «Своя игра») и **«Жарыс»** — соревнование на скорость, как Kahoot.
- **Игра через QR-код** — ученики заходят с телефонов по коду из 6 цифр, правильность и очки считает сервер.
- **Результаты** — таблица учеников и разбор по вопросам: процент верных ответов и самая частая ошибка.

### 👩‍🏫 Для учителя
- Интерфейс на **казахском и русском**, крупные кнопки, тёмная тема и регулируемый размер текста.
- **История** — уроки и проведённые игры с результатами.
- **Библиотека** — готовые уроки, которые можно скопировать себе.
- **Құралдар** — виртуальные опыты PhET, справочник формул по физике 7–11 классов, перевод единиц.

### 🔐 Администрирование
- Вход по логину и паролю, роли «администратор» и «учитель», коды приглашения.
- Админка: учителя, расход и ошибки AI, дневные лимиты запросов, статистика, библиотека уроков.

## 🚀 Как запустить у себя

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
git clone https://github.com/MarlenGO/sabaq-ai.git
cd sabaq-ai
npm install
```

Скопируйте `.env.example` в `.env.local` и заполните:

- `GEMINI_API_KEY` — ключ из [Google AI Studio](https://aistudio.google.com/apikey). Без ключа сайт работает в демо-режиме.
- `SUPABASE_URL` и `SUPABASE_SECRET_KEY` — из настроек проекта Supabase. Таблицы создаются скриптом `supabase/schema.sql` (выполнить в SQL Editor).

Запуск:

```bash
npm run dev
```

Сайт откроется на http://localhost:3000. Первый зарегистрированный пользователь становится администратором.

> Ключи храните только в `.env.local` — не добавляйте их в код и в git.
