# Sabaq AI

Сайт для учителей Казахстана: по теме урока за пару минут получить презентацию (PPTX) и игру для класса на казахском или русском.

## Как работаем
- Код пишет в основном Claude, Марлен изучает каждый шаг и делает небольшие задачи сам. Объясняй решения простыми словами, новые понятия — коротко при первом появлении.
- Сначала фронтенд на моковых данных, бэкенд (Gemini, PostgreSQL) — потом.
- Работаем в ветках `feat/...`, в `main` напрямую не коммитим.

## Архитектура
- Главный контракт — пакет темы: `src/types/topic-package.ts` (схемы zod → типы TS, JSON Schema для Gemini и проверка данных). Слайды и игры собираются из него по шаблонам без AI. Меняя схему, повышай `schemaVersion` и обновляй моки; лимиты списков — в `limits`, их же используют конструкторы.
- AI: `src/lib/ai/` — `gemini.ts` (единственное место с запросом к Gemini, модель из `GEMINI_MODEL`, по умолчанию `gemini-3.5-flash-lite`), `prompts.ts` (короткие промпты), `generate.ts`. Без `GEMINI_API_KEY` — демо-режим из `src/lib/demo.ts`.
- Хранилище: `src/lib/storage/lessons.ts`, JSON-файлы в `data/lessons/` (в .gitignore). id = хэш «тема+класс+язык» — это и кэш тем. Перед деплоем на Vercel заменить на PostgreSQL (только этот файл).
- API: `POST /api/lessons` (создать или взять из кэша), `GET/PUT /api/lessons/[id]` (автосохранение конструктора), `POST /api/lessons/[id]/jeopardy` («Өз ойын» генерируется отдельно, по запросу).
- Игры: шаблоны в `src/games/registry.tsx`. Шаблон = способ показать часть пакета (`quiz`, `trueFalse`, `jeopardy`), а не новые данные: Тест и Викторина делят одни вопросы. Новая игра = запись в реестре + плеер + (если нужно) редактор в `src/components/games/`.
- Страница урока: `/lesson/[id]` — вкладки «Презентация / Ойындар» и «Конструктор / Алдын ала көру».
- Ключи API только на сервере в `.env.local` (шаблон — `.env.example`), никогда в клиентском коде и не в чате.

## Дизайн интерфейса
- Стиль macOS/iOS: фон `bg-bg`, карточки `bg-surface` с `rounded-2xl`, полупрозрачная панель `bg-glass backdrop-blur-xl`, акцент системный синий `accent`.
- Цвета только через токены из `src/app/globals.css` (`text-label`, `text-label-2`, `bg-fill`, `border-separator` …), без жёстких hex в компонентах — так работает тёмная тема.
- Базовые компоненты в `src/components/ui/` (Button, Card/ListGroup, SegmentedControl, NavBar). Сначала переиспользуй их.
- Размеры текста только через шкалу iOS (`text-body`, `text-subhead`, `text-footnote`, `text-title1` …) в rem, без `text-[17px]`: переключатель «А А А» меняет размер шрифта у `<html>`, и всё должно масштабироваться.
- Тема и размер текста: `src/lib/preferences.ts` (хуки) и `preferences-script.ts` (скрипт в `<head>`, без хуков — его импортирует серверный layout).
- Главный пользователь — учителя 55–60 лет: крупные кнопки (от 44px), понятные подписи вместо одних иконок, подтверждение перед удалением, автосохранение.
- Стиль интерфейса ≠ 10 шаблонов презентаций: шаблоны — отдельный конфиг (этап 3+).

## Язык
- Тексты интерфейса на казахском (`lang="kk"`), русский добавим позже через переводы. Проверяй, что казахские буквы (ә ғ қ ң ө ұ ү һ і) отображаются.
