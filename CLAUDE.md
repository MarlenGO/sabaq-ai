# Sabaq AI

Сайт для учителей Казахстана: по теме урока за пару минут получить презентацию (PPTX) и игру для класса на казахском или русском.

## Как работаем
- Код пишет в основном Claude, Марлен изучает каждый шаг и делает небольшие задачи сам. Объясняй решения простыми словами, новые понятия — коротко при первом появлении.
- Сначала фронтенд на моковых данных, бэкенд (Gemini, PostgreSQL) — потом.
- Работаем в ветках `feat/...`, в `main` напрямую не коммитим.

## Архитектура
- Главный контракт — пакет темы: `src/types/topic-package.ts` (схемы zod → типы TS, JSON Schema для Gemini и проверка данных). Слайды и игры собираются из него по шаблонам без AI. При несовместимых изменениях схемы повышай `schemaVersion` и обновляй моки (новые необязательные поля, как `templateId`, версию не меняют); лимиты списков — в `limits`, их же используют конструкторы.
- AI: `src/lib/ai/` — `gemini.ts` (единственное место с запросом к Gemini, модель из `GEMINI_MODEL`, по умолчанию `gemini-3.5-flash-lite`), `prompts.ts` (короткие промпты), `generate.ts`. Без `GEMINI_API_KEY` — демо-режим из `src/lib/demo.ts`; демо-урок из кэша при появлении ключа создаётся заново. Gemini отвечает 400 INVALID_ARGUMENT на «тяжёлые» схемы, поэтому `toGeminiSchema` убирает `maxItems` (количество задаёт промпт, лимиты проверяет zod). Ключ — только в `.env.local`, не в `.env.example` (он в git).
- База — Supabase (Postgres) через REST без библиотек: `lib/db.ts` (`select/insert/update/upsert/remove/count`, секретный ключ только на сервере, RLS включён без правил). Схема — `supabase/schema.sql` (запустить в SQL Editor). Ключи `SUPABASE_URL`, `SUPABASE_SECRET_KEY` — в `.env.local` и в Vercel.
- Хранилище: `lib/storage/` — `lessons.ts` (урок целиком в `data` jsonb + колонки для списков; id случайный, у каждого учителя свои уроки; общий кэш AI `ai_cache` по `cacheKey` = хэш «тема+класс+язык(+предмет, кроме физики)(+вид, кроме урока)»; повторный запрос той же темы открывает свой урок), `rooms.ts` (rooms/players/answers, уникальный ключ (ученик, вопрос) не даёт ответить дважды), `activity.ts`, `usage.ts` (журнал запросов к AI, дневной лимит `DEFAULT_DAILY_LIMIT`, у админов без лимита; оборачивай вызовы AI в `tracked`).
- Вход: свой, без писем (`lib/auth.ts`): логин (email или слово) + пароль scrypt, cookie `sabaq-session` на год (в базе хэш токена). Роли admin/teacher, статусы pending/active/blocked; первый зарегистрированный — админ; с кодом приглашения учитель сразу активен. Для мамы — одноразовая ссылка `/login/link/[токен]` из админки. Страницы — `requireUser()/requireAdmin()` внутри Suspense, API — `currentUser()` → `apiError("unauthorized")`; `src/proxy.ts` только переадресует без cookie на `/login`. Открыто без входа: `/login`, `/play`, ученические API комнат. Свой урок — `canWrite` (удаление — `DELETE /api/lessons/[id]`), чужой из библиотеки (`featured`) — только просмотр и «Көшіріп алу» (`/api/lessons/[id]/copy`).
- Админка `/admin` (вкладки: учителя и коды приглашения, «Тарих», расход AI по дням и учителям, ошибки AI, статистика, библиотека): `lib/admin.ts` + `components/admin/`, API `/api/admin/*` через `adminOrError()`. «Тарих» (`AdminHistory.tsx`, `loadHistory`/`deleteHistory`, `POST /api/admin/history`): уроки и QR-игры всех учителей с фильтром по учителю и поиском; админ удаляет урок (вместе с его QR-играми и записями activity), QR-игру или всю историю учителя (аккаунт остаётся). На вкладках «AI» и «Қателер» — «Тарихты тазалау» (`cleanup`, `POST /api/admin/cleanup`): журнал AI до сегодня и ошибки AI (сегодняшнее не трогаем — по нему дневной лимит).
- Вкладки админки — `components/admin/AdminTabs.tsx`: нажатая подсвечивается сразу (страница вкладки собирается на сервере), у содержимого своя `<Suspense key={tab}>`. Запросы к Supabase идут ~130 мс каждый — в загрузчиках админки делай их одновременно (`Promise.all`), а не друг за другом.
- Вкладка «БД» в админке (`lib/admin-db.ts`, `POST /api/admin/db`): строки и размер таблиц (размер — функция `db_sizes` из `schema.sql` через `rpc`, без неё только строки) и чистка мусора: истёкшие входы/ссылки и кэш AI старше 30 дней, кроме документов, которые ещё есть в чьей-то «Тарих» (ключ пересчитывается `documentKey` из записи activity). Документы (ҚМЖ, тест…) хранятся ТОЛЬКО в `ai_cache` — чистка «Тарих» их не удаляет.
- Құралдар `/tools` (`components/tools/Tools.tsx`, данные `data/physics.ts`): опыты PhET в iframe (`?locale=kk|ru`), справочник формул 7–11 классов с поиском, постоянные, перевод единиц, конвертер — ссылки на convertio.co. Таймер для урока (`components/tools/Timer.tsx`, `?tab=timer`): минуты одним нажатием, ±1 минута, полный экран, сигнал через WebAudio.
- «Орнату» (значок сайта на рабочем столе, PWA): `app/manifest.ts`, значки из логотипа — `node scripts/make-icons.mjs`; событие `beforeinstallprompt` ловит `installScript` в `<head>`, кнопка `ui/InstallButton.tsx` возле логотипа в меню слева видна, только пока браузер (Chrome/Edge) может установить сайт.
- Картинки на слайды «текст+рисунок» и «большой рисунок» при создании урока ищутся сами (`lib/slide-images.ts`, Wikimedia по `imageQuery` примеров; поиск — `lib/images.ts`), хранятся ссылкой в `pkg.deck[id].image`; в PPTX — `addImage` с подписью автора, без картинки — заглушка PowerPoint.
- Режим на главной «AI жазады / Бос жоба» (`mode` в запросе): пустой проект — заготовка с подсказками из `emptyContent` (`lib/demo.ts`), `source: "empty"`, случайный id без кэша.
- Кнопка «AI» у каждого слайда, вопроса теста, утверждения и вопроса «Өз ойын»: `POST /api/lessons/[id]/generate` (`types/ai.ts`, `generatePart` + `partPrompt`) пишет одну часть, сервер её не сохраняет — страница вставляет её как обычную правку, поэтому работает «Болдырмау» (`components/lesson/AiButton.tsx`, `AiProvider`; без ключа кнопок нет). Для слайда что брать/куда класть — `slideAiPart` в `SlideFields.tsx`.
- API: `POST /api/lessons` (создать или взять из кэша), `GET/PUT /api/lessons/[id]` (автосохранение конструктора), `POST /api/lessons/[id]/jeopardy` («Өз ойын» генерируется отдельно, по запросу).
- Игры: шаблоны в `src/games/registry.tsx`. Шаблон = способ показать часть пакета (`quiz`, `trueFalse`, `jeopardy`), а не новые данные: Тест и Викторина делят одни вопросы. Новая игра = запись в реестре + плеер + (если нужно) редактор в `src/components/games/`.
- Презентация: `src/slides/`. `templates.ts` — шаблоны (цвета, украшение; шрифт везде Times New Roman); новый шаблон = новый объект. `layout.ts` — `buildSlides` превращает пакет в слайды из элементов (rect/circle/text) в % и пунктах. Их рисуют два «художника»: `components/slides/SlideCanvas.tsx` (превью) и `export-pptx.ts` (PPTX через pptxgenjs, в браузере). Меняй раскладку только в `layout.ts`, тогда превью и файл не разойдутся. Два разных выбора: **стиль** (`templates.ts`, `templateId` — цвета/шрифты, в интерфейсе «Стиль») и **вид презентации** (`deckType`: урок, открытый урок/конкурс, отчёт, доклад, классный час, родительское собрание, аттестация). Вид = список слайдов в `slides/structures.ts`: раскладка (`layoutSchemas` в topic-package) + тексты-подсказки kk/ru + иконки. Правки учителя — `pkg.deck[id слайда]`, проверяются схемой раскладки при чтении (`slideData`); у вида «урок» id прежние (goals, textImage…). Новый вид = значение в `deckTypeSchema` + список в `structures` + `deckTypes` в словарях + строка в `deckTypePrompt`. Вид входит в хэш id урока (кроме «урока»).
- Дизайны слайдов (`look` в пакете, `slides/looks.ts`): 7 оформлений — beles (Белес), syzba (Сызба), journal (Журнал), mosaic (Мозаика), official (Ресми есеп), attest (Аттестация), method (Әдістемелік кеңес). У каждого свои шрифты (Office: Cambria, Calibri, Palatino Linotype, Arial, Times New Roman, Segoe UI; Georgia нельзя — в ней нет ә ғ қ ң ө ұ ү һ), рамка, заголовок, карточки, метки и титульный слайд; раскладки по видам слайдов общие и собираются из этих деталей. Без `look` дизайн берётся по виду презентации (`lookOf` в `templates.ts`: урок — beles, отчёт — official, доклад — method…). Цвета — стиль с тем же id, что и дизайн (`templateOf`), учитель меняет их в «Слайд түсі» (popover со всеми стилями); при выборе дизайна `templateId` сбрасывается. Выбор дизайна — `components/slides/LookPicker.tsx` (по два слайда каждого дизайна). `look: "classic"` — прежняя раскладка `layout.ts` + `designs.ts`. Элементы умеют свой цвет `hex`, шрифт `face`, курсив и рамку `line` у rect. Шрифт учитель меняет в «Шрифт» (`pkg.font`, `FontPicker.tsx`, 8 шрифтов Windows/Office с казахскими буквами — `fontSchema`): `templateOf` и `lookSlides` подменяют им шрифты дизайна. «Вид презентации» — кнопка с всплывающими карточками; переключатель «Конструктор / Алдын ала көру» у презентации стоит под «PPTX жүктеу». Проверка: `npm run sample:pptx` → `data/samples/<дизайн>-<вид>.pptx`.
- Оформление вида презентации (только для `look: "classic"`) — `slides/designs.ts`: у каждого из 7 видов своя рамка на всех слайдах (`frame`), украшение заголовка (`heading`, по `role: "heading"` у текста) и свой титульный слайд (`title`): урок — тетрадь с полями, открытый урок — лента с золотом, отчёт — полоса и подвал с номером, доклад — строгие линейки, классный час — мягкие круги, собрание — шапка, аттестация — двойная рамка и место под фото. У каждого вида свой стиль по умолчанию (`byDeckType` в `templates.ts`: festive, corporate, academic, warm, calm, elegant; у урока — по предмету), учитель может выбрать любой. Второй цвет стиля для золотых деталей — `template.detail`; у `rect` можно задать свой `color`. Простые элементы и `fitFontSize` — `slides/elements.ts`.
- Документы (колонка «Құжаттар» на странице предмета): ҚМЖ, тест для печати (10–30 вопросов), БЖБ, PISA, жұмыс парағы. Жұмыс парағы (`worksheet`) — только на казахском (форма и `POST /api/documents` ставят `kk`): сәйкестендіру, сөзжұмбақ, бос орын, дұрыс/бұрыс, сұрақтар, рефлексия, на отдельной странице — ответы учителю. AI даёт слова и подсказки, сетку кроссворда раскладывает код (`documents/crossword.ts`; для этого в модели есть `Cell.blank`, `Row.height`, `Table.grid`). Перемешивание вариантов — детерминированное (`shuffled` в `render.ts`), чтобы лист и Word совпадали. Схемы — `types/documents.ts`; сборка — `documents/render.ts` → модель `documents/model.ts` (абзацы и таблицы с ширинами колонок в twips, объединения, жирные подписи «…:» в начале строки), из неё `documents/html.ts` (предпросмотр и печать/PDF) и `documents/docx.ts` (настоящий .docx без библиотек: свой ZIP, таблицы с фиксированными колонками, строка заголовков повторяется на страницах). Пустые бланки — `documents/empty.ts`. Страница — `components/documents/DocumentWorkspace.tsx` (узкая форма слева, справа лист A4, уменьшенный под ширину колонки через `zoom`).
- ҚМЖ — по скиллу `kmzh-docx-generator` (`.claude/skills/`): Word собирается из размеченного шаблона `templates/kmzh.docx` (docxtemplater + pizzip, `lib/kmzh/fill.ts`; шаблон руками в Word не править — разметка через `build_template.py` скилла), лист на сайте и печать — `lib/kmzh/preview.ts`; оба из ОДНОГО JSON `KmzhDoc` (поля учителя + ответ AI, `lib/kmzh/schema.ts`), поэтому совпадают. Один запрос к Gemini на ҚМЖ (`lib/kmzh/generate.ts`: правила заданий `RULES` + образец `lib/kmzh/sample.json`), баллы 4 + 6 = 10 и ЕБҚ 10 проверяет схема (иначе один повтор). Бөлім и оқу мақсаты учитель может не писать — AI предлагает, на листе пометка «тексеріңіз». Всё через `POST /api/documents` (`{ word: KmzhDoc }` → .docx); ключ кэша с `v2`, в «Тарих» у ҚМЖ `v: 2` — старые ҚМЖ показывают «ескі формат» и кнопку пересоздать. 3 или 4 задания (`taskCount`): при 4 в шаблоне появляется строка «4-тапсырма» (условие `{#has_task4}`, добавлена скриптом скилла `add_task4.mjs`), минуты заданий — теги `{taskN_min}` (8/7/8 или 6/6/6/5, `taskMinutes`), баллы 4 + 6 или 3 + 4 + 3; при 4 заданиях Gemini получает `kmzhAi4Schema` и правила `FOUR_TASKS`. Проверка шаблона: `node scripts/test-fill.mjs templates/kmzh.docx src/lib/kmzh/sample.json tmp/kmzh-test.docx`.
- «Менің құжаттарым» `/documents` (`components/documents/MyDocuments.tsx`, ссылка в меню и в колонке «Құжаттар» предмета `?subject=`): таблица `documents` (`lib/storage/my-documents.ts`) — у учителя своя копия каждого нового документа, `data = { fields: поля формы (DocFields), content: ответ AI }`, .docx не храним. `POST /api/documents` создаёт копию и отдаёт `docId` (не при `again`; нет таблицы — документ всё равно отдаётся), `GET/PUT/DELETE /api/documents/[id]`; DocumentWorkspace автосохраняет поля через 800 мс, пока лист = этот документ, `?doc=id` открывает его с сервера. Чистка кэша и «Тарих» таблицу не трогает.
- API `POST /api/documents`: ответ AI — в общем `ai_cache` с ключом `doc-…` (`lib/storage/documents.ts`, у теста в ключе и число вопросов), учёт в `tracked(…, "document")`. Последний документ хранится в браузере (`sabaq-doc-<вид>-<предмет>`). `gemini.ts` при 503/500 сам повторяет запрос (через 3 и 8 с).
- Конструктор презентации — по слайдам: `components/slides/SlideEditor.tsx` (миниатюры с заголовками + выбранный слайд) и `SlideFields.tsx` (поля по раскладке). При создании с AI тексты всех заготовок пишутся параллельно с пакетом темы (`generateDeck`, одна схема на все слайды); то же — кнопка «Барлық слайдты AI-мен толтыру» (`FillDeckButton`, part `deck`) — только на странице выбора вида; в конструкторе у слайда своя кнопка «Осы слайдты AI-мен толтыру». AI не выдумывает личные данные для отчётов/портфолио — ставит «…».
- «Жоспар» `/plan` — КТП учителя (`components/plan/`): Word (.docx) или Excel (.xlsx; .doc и PDF не принимаем) → `lib/plans/read-file.ts` достаёт таблицы текстом «| ячейка |» через pizzip (даты Excel по стилю) → `POST /api/plans/parse` → один запрос к Gemini (`lib/plans/parse.ts`, `planAiSchema`, учёт `tracked(…, "plan")`), тема, которой нет в файле дословно, помечается `unsure` («тексеріңіз»). Учитель проверяет и правит уроки (черновик в localStorage `sabaq-plan-draft`), «Сақтау» → `POST /api/plans`; дальше автосохранение `PUT /api/plans/[id]`. Таблица `plans` (уроки в `lessons` jsonb, типы `types/plan.ts`, хранилище `lib/storage/plans.ts`). «ҚМЖ жасау» у урока — ссылка `kmzhHref` на страницу ҚМЖ с `?topic&section&objective&date&plan&lesson`: DocumentWorkspace создаёт ҚМЖ, пишет его в «Тарих» и отмечает урок (`POST /api/plans/[id]/kmzh`, `kmzhAt`); `&done=1` — просто открыть из кэша. Строка на 2 часа («21-22») — два урока; БЖБ/ТЖБ доотмечает код (`kindOf` в `parse.ts`), «БЖБ№1» в конце темы в ҚМЖ не идёт (`kmzhHref`). Страница держится в `<Activity>`, поэтому при каждом показе, при возврате на вкладку и по событию `PLAN_CHANGED` (его шлёт DocumentWorkspace после отметки) перечитывает планы `GET /api/plans`. Пробные КТП: `node tmp/make-ktp.mjs`, чтение — `npx tsx tmp/read-ktp.mts файл` (с `AI=1` и `--env-file=.env.local` — и разбор Gemini).
- Навигация (`components/ui/NavBar.tsx` + `NavLinks.tsx`): на компьютере (lg) закреплённое меню слева шириной 64 (layout сдвигает содержимое `lg:pl-64`), на телефоне — панель сверху. Логотип — книга на квадрате цвета `accent` (`fill-accent`).
- Путь создания: главная `/` — сетка предметов с поиском (`components/home/SubjectGrid.tsx`, карточка: обложка тёмного цвета предмета с кольцами и иконкой Lucide, снизу название) → `/subject/[предмет]` — три списка «Құжаттар», «Презентация», «Ойындар» с поиском (`SubjectMenu.tsx`) → `/subject/[предмет]/[вид или игра]` — одна форма: тема (без подсказок и примеров), язык, класс 6–11 в одну строку, AI/пустой проект в одну строку (`CreateForm.tsx`). Игра открывает урок с `?game=`. Цвета/иконки предметов, иконки видов, игр и документов — `data/catalog.ts` (`kindOf` различает вид презентации и игру). Иконки из `lucide-static` — компонент `ui/LucideIcon.tsx`.
- Кнопки списков в конструкторах (удалить, ↑ ↓ вместо перетаскивания) — `components/ui/ItemButtons.tsx`, помощники `moveItem`/`replaceAt` — `ui/field.ts`. «Өз ойын» на табло — темы строками, как в «Своей игре»; учитель может довести тем до 6 (`limits.jeopardy`), AI даёт 3–5.
- Иконки: `src/slides/icons.ts` (Lucide, ISC). В превью SVG, в PPTX — PNG (в браузере через canvas, в скрипте через resvg), чтобы открывалось и в старом PowerPoint.
- Место под картинку (`type: "image"`) в PPTX — настоящая заглушка PowerPoint «нажмите, чтобы вставить рисунок» через макет слайда. pptxgenjs 4.0.1 теряет у неё `type="pic"`, поэтому `pptxBytes` дописывает его в XML. Скругление `rectRadius` в pptxgenjs — доля от короткой стороны (не от половины).
- `npm run sample:pptx` — пробные PPTX во всех шаблонах в `data/samples/`, их можно открыть в PowerPoint.
- Игра через QR (переключатель «Экранда / QR арқылы», флаг `qr` в реестре игр; Өз ойын — только экран): учитель создаёт комнату (`POST /api/rooms`, код из 6 цифр, копия вопросов), ученики заходят на `/play/[код]` и отвечают в своём темпе; правильность проверяет сервер, ответы на телефон заранее не уходят. Экран учителя `components/games/RoomHost.tsx` опрашивает `/api/rooms/[код]` каждые 2 с. Экран учителя и управление игрой — только её учителю.
- Перемешивание в QR-игре (галочка при запуске, `room.shuffle`): при входе ученику записываются `order`/`optionOrders`, `/play` отдаёт вопросы в его порядке, а `resolveAnswer` (`lib/rooms.ts`) переводит номер вопроса и кнопки обратно в исходные — ответы и статистика хранятся по исходным номерам.
- «Жарыс» (`race`, как Kahoot, `live: true` в реестре — только через QR): `room.live` — фаза lobby/question/reveal/finished; учитель ведёт её `POST /api/rooms/[код]/live` (start/reveal/next), экран учителя `RaceRoom` в `RoomHost.tsx` сам показывает ответ, когда вышло время или ответили все. Ответ принимается только на текущий вопрос и пока идёт время (`RACE_SECONDS` + 2 с), очки и время считает сервер. Оба экрана опрашивают сервер раз в секунду. Плитки ▲◆●■ — `components/games/race.ts`.
- Анализ по вопросам: `questionStats` → `QuestionStats` (в `ResultsTable.tsx`) на экране учителя и в истории игры: % верных, красным — меньше половины, самый частый неверный ответ.
- Пока сайт не опубликован, телефоны заходят по адресу ноутбука в Wi-Fi (`/api/network`); для этого в `next.config.ts` есть `allowedDevOrigins` для 192.168.*.* и т.п.
- Картинки в вопросах (тест/викторина и «Өз ойын»): храним только ссылку `{ url, credit }` (`imageSchema`, только https), файлы не храним. Выбор — `components/games/ImagePicker.tsx`: поиск в Wikimedia Commons через `/api/images` (без ключа, с User-Agent) или вставка ссылки. Показ — `components/ui/RemoteImage.tsx` (`<img referrerPolicy="no-referrer">`). В схемах для AI (`quizQuestionSchema`, `jeopardySchema`) картинок нет, чтобы модель не выдумывала ссылки; хранимые версии — `quizItemSchema`, `jeopardyStoredSchema`.
- История (`/history`, ссылка «Тарих» в панели): `lib/history.ts` собирает её из уроков (createdAt), комнат QR-игр (с результатами, страница `/history/game/[код]`) и журнала activity (`lib/storage/activity.ts`) — туда пишутся скачанный PPTX и игра на экране (при первом ответе) через `lib/track.ts` → `POST /api/activity`, а созданный документ — сам `POST /api/documents` (из «Тарих» документ открывается по `?topic=&grade=&lang=&count=` и берётся из кэша, `again: true` — без новой записи). Удаление галочками («Барлығын таңдау», кнопка появляется при выборе) — `components/ui/Selection.tsx`, у учителя `POST /api/history/delete` (только своё), в админке `POST /api/admin/history`; оба через `deleteSelection` (`lib/storage/history-delete.ts`), урок удаляется вместе с его QR-играми и событиями.
- Даты: `lib/dates.ts`, пояс `Etc/GMT-5` (весь Казахстан с 2024 — UTC+5; «Asia/Almaty» в старой базе поясов Node 20.11 ещё UTC+6 и ломает гидратацию). Формат собираем сами (30.10.2026 17:08), не через локаль kk-KZ — в Node её нет. «Сегодня/вчера» считаем на сервере.
- Страница урока: «Артқа» = назад по истории браузера; у только что созданного урока (`&new=1`, API отвечает `created: true`) сначала диалог «Тарихқа сақтаймыз ба?» — «Жоқ, өшіру» удаляет урок, чтобы история не засорялась пустыми проектами. Со страницы игры ссылки на презентацию нет. Адреса документов — с приставкой `doc-` (`docPath`), т.к. id документа «test» совпадает с игрой «Тест».
- Страница урока: `/lesson/[id]?tab=slides|games` — только то, что выбрано на главной (вторая часть — тихой ссылкой), и «Конструктор / Алдын ала көру». `?view=1` — только просмотр (из истории), `&game=` — какую игру открыть.
- Состояние страниц сохраняется при переходах (cacheComponents держит их в `<Activity>`): флаги «загрузка» не делаем через useState перед `router.push`, а используем `useTransition`, иначе при возврате кнопка «крутится» вечно.
- Ключи API только на сервере в `.env.local` (шаблон — `.env.example`), никогда в клиентском коде и не в чате.

## Дизайн интерфейса
- Стиль «спокойная тетрадь», без «ИИ-шных» приёмов: фон бледный шалфей `bg-bg` (#eef1eb), белые листы `bg-surface` без теней (только тонкая линия `shadow-card`), один акцент — зелёный «школьной доски» `accent` (#2e6a4f). Шрифт один — Nunito (`next/font`, с cyrillic-ext). Не возвращать: градиенты-украшения, слова в заголовке другим цветом, ПРОПИСНЫЕ подписи, «подпрыгивание» карточек при наведении, искры ✨.
- Цвет предмета — `subjectLook[предмет].hue` (`data/catalog.ts`); `subjectColors()` (`components/home/SubjectBadge.tsx`) даёт `--tile` (мягкий фон) и `--ink` (иконка) через color-mix — работает в обеих темах. Списки (виды, игры) — один белый лист со строками-разделителями, а не россыпь карточек.
- Цвета только через токены из `src/app/globals.css` (`text-label`, `text-label-2`, `bg-fill`, `border-separator` …), без жёстких hex в компонентах — так работает тёмная тема.
- Базовые компоненты в `src/components/ui/` (Button, Card/ListGroup, SegmentedControl, NavBar). Сначала переиспользуй их.
- Размеры текста только через шкалу iOS (`text-body`, `text-subhead`, `text-footnote`, `text-title1` …) в rem, без `text-[17px]`: переключатель «А А А» меняет размер шрифта у `<html>`, и всё должно масштабироваться.
- Тема и размер текста: `src/lib/preferences.ts` (хуки) и `preferences-script.ts` (скрипт в `<head>`, без хуков — его импортирует серверный layout).
- Главный пользователь — учителя 55–60 лет: крупные кнопки (от 44px), понятные подписи вместо одних иконок, подтверждение перед удалением, автосохранение.
- Стиль интерфейса ≠ 10 шаблонов презентаций: шаблоны — отдельный конфиг (этап 3+).

## Язык
- Интерфейс на казахском и русском: переключатель ҚАЗ/РУС в панели, выбор в cookie `sabaq-lang`. Словари `src/i18n/kk.ts` (эталон) и `ru.ts` — новый текст добавляй в оба, иначе tsc ругается. В клиентских компонентах `useT()` из `@/i18n/client`, в серверных и API `await getT()` из `@/i18n/server` (читает cookie — только внутри Suspense; layout уже обёрнут). Ошибки API — `apiError("ключ", статус)`: текст на языке сайта + `code` для кода.
- Язык сайта ≠ язык урока: слайды, вопросы, «Шын/Жалған» — на языке урока.
- Проверяй, что казахские буквы (ә ғ қ ң ө ұ ү һ і) отображаются.
