## Как запустить дома

1. Склонировать и перейти на ветку:
   ```powershell
   git clone https://github.com/MarlenGO/sabaq-ai.git
   ```
   ```powershell
   cd sabaq-ai; git checkout feat/subjects-redesign
   ```
2. Установить пакеты: `npm install`
3. Создать `.env.local` по образцу `.env.example` и вставить ключи
   (их значения есть в Vercel → проект → Settings → Environment Variables;
   **в git и в чат ключи не класть**):
   - `GEMINI_API_KEY` — из https://aistudio.google.com/apikey
   - `SUPABASE_URL` и `SUPABASE_SECRET_KEY` — из Supabase → Project Settings → API Keys
4. Запустить: `npm run dev` → http://localhost:3000
5. Перед коммитом: `npx tsc --noEmit` и `npm run lint`.

База общая с сайтом на Vercel (тот же Supabase), поэтому локально входишь своим обычным логином.

## Что сделать дальше

1. **Обновить Next.js** (на рабочем ноутбуке нельзя ставить пакеты, дома можно):
   `next build` предупреждает, что в версии 16.4.3 найдена уязвимость, и иногда
   останавливает сборку — так может случиться и на Vercel.
   ```powershell
   npm install next@latest
   ```
   Затем `npm run build`, проверить сайт и закоммитить `package.json` + `package-lock.json`.
2. **Проверить на сайте после входа** (на рабочем ноутбуке без входа не проверялось):
   страницу урока — выбор стиля (только название и картинка), Times New Roman на слайдах,
   новые дизайны 7 видов в превью и в скачанном PPTX.
3. **Проверить документы с AI**: ҚМЖ и БЖБ по 2–3 темам разных предметов, открыть .docx в Word.
   Известные недочёты AI: изредка неверный раздел программы, опечатки, числа в задачах,
   не совпадающие со справочником, — учителю стоит пролистать документ.
4. **Перенести ветку в `main`**, чтобы обновился сайт на Vercel:
   ```powershell
   git checkout main; git merge --ff-only feat/subjects-redesign; git push origin main
   ```
5. Идеи на потом (ещё не начаты): «Жұмыс парағы» (лист заданий для учеников к ҚМЖ, как в
   примерах учителя), СОР/СОЧ (ТЖБ), калькулятор оценок, грамоты, генератор задач по физике.
