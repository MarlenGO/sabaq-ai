# Sabaq AI — где мы остановились

Файл, чтобы продолжить работу на домашнем компьютере. Подробные правила
и устройство кода — в [CLAUDE.md](CLAUDE.md); здесь только состояние проекта.

_Обновлено: 27.11.2026._

## Состояние

- **Сайт на Vercel работает из ветки `main`**: вход и роли, админка (вкладки «Тарих», AI, «Қателер», «БД»), уроки, игры, документы (ҚМЖ из Word-шаблона, тест, БЖБ, PISA, жұмыс парағы), «Жоспар» (КТП из Word/Excel), Құралдар, таймер, установка значка сайта.
- **Новая работа — в ветке `feat/slide-colors`** (отправлена на GitHub, в `main` ещё не перенесена). Это доработка презентаций:
  - **7 дизайнов слайдов** (`src/slides/looks.ts`): Белес, Сызба, Журнал, Мозаика, Ресми есеп, Аттестация, Әдістемелік кеңес. У каждого свои рамка, заголовки, карточки, метки и титульный слайд. Выбор — плитки с превью вашего урока (`LookPicker.tsx`). Без выбора дизайн берётся по виду презентации.
  - **«Слайд түсі»** — цвет слайдов во всплывающем списке (вместо 11 почти одинаковых стилей).
  - **«Шрифт»** — 8 шрифтов Windows/Office, в которых есть все казахские буквы: Times New Roman, Cambria, Palatino Linotype, Arial, Calibri, Segoe UI, Verdana, Tahoma. Georgia, Trebuchet, Century Gothic и др. казахских букв не имеют — их не добавлять.
  - **«Презентация түрі»** — одна кнопка, по нажатию всплывают карточки видов.
  - Переключатель «Конструктор / Алдын ала көру» — под кнопкой «PPTX жүктеу»; ссылка «Осы тақырыпқа ойын жасау» убрана.
  - В конструкторе кнопка AI у слайда заполняет **только этот слайд**; «Барлық слайдты AI-мен толтыру» — только на странице выбора вида.
  - На странице предмета у каждой колонки (Құжаттар / Презентация / Ойындар) ссылка «Тарих» — открывает историю сразу с нужным фильтром (`/history?show=document|lesson|game`).
  - Пробные файлы всех дизайнов: `npm run sample:pptx` → `data/samples/<дизайн>-<вид>.pptx`.
- **«Менің құжаттарым» — ветка `feat/my-documents`** (от `feat/slide-colors`, отправлена на GitHub): у каждого учителя своя копия каждого созданного документа (ҚМЖ, тест, БЖБ, PISA, жұмыс парағы) в таблице `documents` — JSON с полями формы и ответом AI, .docx не храним. Правки полей автосохраняются (800 мс), страница `/documents` с поиском, фильтром по виду и предмету и удалением; ссылка в меню и в колонке «Құжаттар» предмета. Чистка кэша и «Тарих» её не трогает. SQL уже запущен в Supabase, проверено в браузере.
- **Дизайн сайта** — прежний (из `main`). Школьный «тетрадный» дизайн сохранён в ветке `feat/notebook-design` на будущее.

## Как запустить дома

1. Склонировать (если ещё нет) и перейти на ветку:
   ```powershell
   git clone https://github.com/MarlenGO/sabaq-ai.git
   ```
   ```powershell
   cd sabaq-ai; git fetch; git checkout feat/slide-colors; git pull
   ```
2. Установить пакеты: `npm install`
3. Создать `.env.local` по образцу `.env.example` и вставить ключи
   (их значения есть в Vercel → проект → Settings → Environment Variables;
   **в git и в чат ключи не класть**):
   - `GEMINI_API_KEY` — из https://aistudio.google.com/apikey
   - `SUPABASE_URL` и `SUPABASE_SECRET_KEY` — из Supabase → Project Settings → API Keys
4. Запустить: `npm run dev` → http://localhost:3000
5. Перед коммитом: `npx tsc --noEmit` и `npm run lint`.

База общая с сайтом на Vercel (тот же Supabase), поэтому локально входишь своим обычным логином.

## Что сделать дальше

1. **«Менің құжаттарым»** — готово в `feat/my-documents`, перенести в `main` вместе с `feat/slide-colors`. Идеи дальше: правка текста документа прямо на листе; из «Тарих» открывать сохранённую копию (`?doc=`), а не кэш.
1a. **Проверить презентации**: скачать PPTX в 2–3 дизайнах, открыть в PowerPoint, посмотреть казахские буквы и выбранный шрифт.
2. **Перенести `feat/slide-colors` (и `feat/my-documents`) в `main`**, чтобы обновился сайт на Vercel (лучше через Pull Request на GitHub).
3. **Запустить в Supabase SQL функцию `db_sizes`** из `supabase/schema.sql` (SQL Editor) — без неё вкладка «БД» в админке показывает только число строк, без размеров.
4. **Ошибка в консоли на странице урока**: Next.js ругается на `Date.now()` в `requireUser` («unstable value while prerendering»). Работе не мешает, но стоит поправить.
5. **Обновить Next.js** (на рабочем ноутбуке нельзя ставить пакеты, дома можно): `npm install next@latest`, затем `npm run build`, проверить сайт и закоммитить `package.json` + `package-lock.json`.
6. Идеи на потом: СОР/СОЧ (ТЖБ), калькулятор оценок, грамоты, генератор задач по физике.

на рабочем ноутбуке (`Desktop\КМЖ`) и в репозиторий **не** добавлялись: там ФИО учителей.
Всё нужное из них уже перенесено в код: таблицы и ширины колонок — `src/documents/render.ts`,
стиль заданий — `documentTask.kmzh` в `src/lib/ai/prompts.ts`. Если понадобятся снова —
перенеси папку на домашний ПК вручную (флешка, почта), но не в папку проекта.
